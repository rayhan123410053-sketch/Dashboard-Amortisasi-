# Dashboard Amortisasi

Dashboard interaktif untuk menghitung dan memvisualisasikan amortisasi pinjaman, dibuat dengan Python (Shiny, Pandas, Matplotlib, Seaborn).

## Cara menjalankan
1. Buka file notebook `Codingan_amortisasi.ipynb`, lalu klik tombol **Open in Colab**.
2. Jalankan semua cell secara berurutan (Runtime > Run all).
3. Dashboard akan tampil di bagian output cell terakhir.

## Fitur
- Input jumlah pinjaman, suku bunga, dan tenor
- Tabel amortisasi bulanan
- Grafik visualisasi amortisasi
